## What I am building

I am focused on **BiliPai**, a third-party Android client for Bilibili built around a simple goal: keep the watching experience native, quiet and adjustable.

- Native Android UI with Kotlin, Jetpack Compose and Material 3.
- Daily Bilibili workflows: feed, search, video, bangumi, live, dynamic, messages and profile.
- Player-first details: DASH, danmaku, gestures, background playback, PiP, audio mode and playback memory.
- Extensible app surface: built-in plugins, JSON rule plugins and native plugin experiments.
- Tablet and foldable support with large-screen navigation and theater layouts.
- Recently learning Android reverse engineering and low-level networking to better understand playback, protocol and runtime behavior.

## BiliPai at a glance

| Area | Focus |
| --- | --- |
| Experience | Clean Bilibili client without heavy official-app distractions |
| Playback | Video, bangumi, live, danmaku, background playback, PiP and audio mode |
| Design | Material You, Material 3 Expressive, liquid glass, adaptive layouts |
| Extensions | SponsorBlock, ad filtering, danmaku tools, eye protection, Today Watch, CDN region preference |
| Platform | Android 8.0+, optimized for modern Android and larger screens |

## Current direction

- Keep the client practical for daily use before adding more surface area.
- Improve playback stability, gesture behavior and screen-state transitions.
- Continue polishing the native Android design language instead of copying web or official-app patterns.
- Make plugin capability boundaries clearer and safer.
- Keep release notes tied to the real shipped diff.
